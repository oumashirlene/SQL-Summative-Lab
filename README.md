# SQL Summative Lab

## Project Overview
This project demonstrates SQL querying, data analysis, and visualization using Python.

## Part 1: Customer and Sales Analysis
- Customer segmentation and credit limit analysis
- Top customer payments
- Product sales and inventory analysis
- Employee and office analysis

## Part 2: IMDb Movie Analysis (2010–2019)
- Exploratory analysis of movie genres and audience ratings
- Visualization of genre ratings
- Business question formulation
- Identification of potential data-cleaning tasks

## Tools Used
- Python
- SQLite
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Files
- `SQLSummativeLab_Completed_Commented.ipynb` — SQL queries, analysis, and visualizations
- `IMDb_SQL_Summative_Lab_Presentation.pptx` — presentation of IMDb findings
